Lily58 Dev Keymap

Four layers for shell-heavy work on an Aurora Lily58 running ZMK. Plain QWERTY on BASE, æøå on a layer, underglow colour per Bluetooth host. The OS stays on the Norwegian layout; the firmware emits the right scancodes so every symbol sits where the map says.

Your constraint is "many hosts, switch a lot", so zero per-host setup wins. The dead-key cost is three macros you never notice.

Where the shell characters live

  • - = / . , ; ' on BASE; Shift gives _ : * for free on the Norwegian layout.
  • SYM, held by the right thumb: brackets as pairs under ring + middle finger on the left hand, one pair per row; $ | \ ~ & * beside them.
  • Right hand on SYM: = " + : on the home row, ! ? @ # ^ above, _ ` € below, Æ Ø Å at their Norwegian spots.
  • PowerShell: $ is left ring on the home row of SYM, | under the left pinky home, \ under the left pinky one row down.

Arrows

HJKL on NAV, held by the left thumb. Home / PgDn / PgUp / End on the row above, word-jump and word-delete on the row below. Left hand gets Shift / Ctrl / Alt / GUI on its home row while NAV is held, so selection and word jumps are one-handed per side.

Switching between PCs

Hold FN (right outer thumb) and press 1 to 5 on the left number row. Each key is a ZMK macro: &bt BT_SEL n followed by &rgb_ug RGB_COLOR_HSB(hue,100,20), so the underglow colour tells you which host you are on before you type. The nice!view shows the profile number as well.

Pair one profile per host (Debian test laptops, corporate Windows, Mac). Keep profile 5 for the odd one. ZMK has no built-in profile-to-colour link; the macro is the way to get it, and it survives reboots because RGB state is saved to flash.

macOS

The Norwegian Mac layout puts brackets and @ on different Option combos, and swaps Cmd for Ctrl. The MAC key on FN toggles a variant of BASE and SYM for that host. Not drawn here; build it when the Mac profile goes in.

Optional: home-row mods

Not in this map. Ctrl and Shift stay physical on the left pinky column, which matters for Ctrl+C / Ctrl+R / Ctrl+L. If you later want fewer pinky reaches, add Miryoku-style home-row mods on BASE and keep this NAV/SYM/FN structure unchanged.

From the Iris

Same alpha block, one more thumb key per side. Your old three layers map onto NAV and SYM plus FN; the extra thumb key is what makes FN a dedicated hold instead of a double-thumb chord. Both shifts held together is Caps Word for ENV_VARS.
